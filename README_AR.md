# تاجر برو — مشروع أندرويد قابل للبناء

هذه حزمة Android Studio مبنية على واجهة تاجر برو المحلية وتضم إعداد GitHub Actions لبناء APK وAAB تلقائيًا.

## بناء الملف على GitHub من الهاتف
1. حمّل ZIP وفك ضغطه.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع **محتويات المجلد** إلى جذر المستودع، بما فيها مجلد `.github`.
4. افتح تبويب Actions، وافق على تفعيل workflows إذا طلب ذلك، ثم شغّل `Build Tajir Pro APK and AAB`.
5. عند نجاح البناء افتح تشغيل workflow ونزّل Artifact باسم `TajirPro-Android-Build`.
6. فك ضغط الـ Artifact؛ ستجد ملفات APK وAAB الناتجة.

## البناء محليًا
يتطلب JDK 17 وGradle 8.9 واتصال إنترنت لتنزيل Android Gradle Plugin.
- APK تجريبي: `gradle assembleDebug`
- APK إصدار: `gradle assembleRelease`
- حزمة المتجر: `gradle bundleRelease`

## حدود النسخة الحالية
- المشروع يضم تطبيق WebView مع وظائف تاجر برو المحلية. البيانات محفوظة داخل WebView على الجهاز.
- لا توجد قاعدة بيانات سحابية أو حسابات تجار مشتركة أو سوق متعدد البائعين في هذه النسخة.
- إصدار release الناتج غير موقّع بمفتاح نشر خاص بك؛ قبل Google Play يجب إنشاء مفتاح توقيع آمن وتكوين التوقيع وعدم مشاركة المفتاح أو كلمة مروره.
- لا أستطيع تأكيد نجاح بناء فعلي قبل تشغيل GitHub Actions؛ الملف هنا هو مصدر البناء، وليس APK مبنيًا.
- راجع الحسابات التجارية واختبرها قبل الاعتماد عليها أو بيع البرنامج على أنه نظام محاسبي رسمي.

## فحوصات مضافة
- يسبق البناء فحص ملفات المشروع وصحة XML وSyntax جافاسكربت بواسطة Node.js.
- تم تحسين التاريخ ليستخدم تاريخ الجهاز المحلي، ومعالجة فشل التخزين برسالة واضحة، واحتساب متوسط تكلفة المخزون المرجّح عند تسجيل مشتريات جديدة.
- هذه الفحوصات لا تغني عن تثبيت APK وتجربة الوظائف على هاتف أندرويد فعلي.
